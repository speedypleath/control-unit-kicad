Wiring Guide

Every connection, given as the actual perfboard hole (column letter + row number, matching the printed grid on your board) — not an abstract header-pin number. Read a grid ref, find that hole, solder.

Power (+5V / +3V3 / VIN) Ground I²C bus (SCL / SDA / IRQ) Signal (per-pin GPIO)
Layout note (2026-08-20 revision): every JST header group now shares one anchor row per group, mirrored left/right to match the physical panel (S1–S6 haptic drivers centered; B1–B4 mirrors B5–B8; J1 mirrors J2; CB1–CB5 near-symmetric about the center column). Because each group shares an anchor row, the same pin number lands on the same row across every connector in the group — so GND (and +3V3/+5V/SCL/SDA for S1–S6) can be bussed with one straight wire along that row instead of home-running each connector separately. All content fits within the physical board's 32×50 hole grid (columns A–Z/A–F, rows 01–50); nothing has been placed past row 50.
Connector standard note: S1–S6 now follow the XH2.54 6-pin Haptic Console Connector Standard v1.1 pinout — pin 1 GND, pin 2 3.3V, pin 3 5V, pin 4 SDA, pin 5 SCL, pin 6 IRQ — matching cables crimped to that spec. The physical hole grid below is unchanged from the previous revision; only which signal sits on which pin (and therefore which row carries which bus) was corrected.
Board re-layout note (2026-08-20, later revision): the Teensy header sockets moved 1 column left / 2 rows up (row 25→23, row 31→29) and R12/R13 shifted 2 columns since the previous revision of this guide. All header/pull-up/LED-resistor grid refs below were re-derived directly from the current haptic-console-control-unit-perfboard.kicad_pcb placement to match. S1–S6, B1–B8, J1/J2, and CB1–CB5 did not move and are unaffected.

Shared bus rails

Run each as one continuous wire past every hole listed, rather than home-running each connector back to the header separately. Rows refer to the connector-side anchor rows below, not the Teensy header rows above.

S1–S6 — haptic drivers (I²C)

Rotated vertical, one per column, centered on the board (cols D–S1…C–S6). GND/SCL/SDA/+5V/+3V3 all fall on the same row across all six — a horizontal bus wire along that row reaches every connector.

R12 / R13 — I²C pull-ups

Sit just below the S-zone, tapping the SDA/SCL/+3V3 rails directly.

B1–B8 — diamond buttons (mirrored)

B1–B4 (left cluster) mirror B5–B8 (right cluster) on the same row band. All eight pin-1 (GND) holes share row 16 — one wire spans the whole row and grounds all eight connectors.

J1 / J2 — joysticks (mirrored)

J1 (left stick) mirrors J2 (right stick). Pin 5 (GND) on both lands on row 35.

CB1–CB5 — LED buttons (near-symmetric)

CB3 sits on the center column; CB2/CB4 and CB1/CB5 mirror around it. Both GND pins (2 and 4) fall on rows 46 and 44 across all five connectors — two possible rail rows, use either or both.

R1–R5 — LED series resistors

One row below CB1–CB5, each resistor under its matching connector's column.

NP1 — numpad

Unchanged by this revision — pushed to the board's right edge (col B) to dodge the Teensy header row it shares rows with. Note: since the header re-layout above, NP1 pin 8 (B23, right edge) and Header A pin 1 (B23, left edge) now compute to the same letter+row — the board's 32-column letter sequence reuses "B" at both ends, so these are two different physical holes despite the identical label. Use the left/right position, not the label alone, to tell them apart.
